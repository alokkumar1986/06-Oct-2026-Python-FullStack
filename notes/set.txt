set :
#==============

list : ordered, mutable, allow duplicate []

tuple : ordered, immutable, allow duplicate ()

set : unordered, immutable, don't allow duplicate {}


set is also collection type. we define set using following

1) [] -- list()
   () -- tuple()
   {} -- set()

s = {'apple', 'orange', 'banana'}
print(type(s)) # <class 'set'>

s = set(('apple', 'orange', 'banana'))
print(type(s)) # <class 'set'>

s = set(['apple', 'orange', 'banana'])
print(type(s)) # <class 'set'>

s = set('apple', 'orange', 'banana') #Error
print(type(s)) # <class 'set'>

empty set:
#==========================

l=[] #empty list
t=() #empty tuple
s={} #empty dict

s= set() #empty set


#set is unordered, immutable, don't allow duplicate :

s = {1, 2, 1, 3, 2, 5}

print(s) #{1, 2, 3, 5} don't allow duplicate


print(s[0]) #set is unordered, hence accessing element using index is not allowed

set does allow indexing and slicing.

how to access the element : using for loop

s = {1, 2, 1, 3, 2, 5}

for I in s:
 print(I)


methods used in set :
#=========================

len()

s = {1, 2, 1, 3, 2, 5}
print(len(s))

add() :  It is used to add item to a set.
update() : It is used to add another set to a set.

remove() : It is used to remove an item. It gives error when item is not present in the set.
discard() : It is used to remove an item. It doesn't give any error if item is not present in the set.


del : To delete the set.
clear() : To clear all the items from set.

union() : It joins two sets
intersection()
difference()
symmetric_differenece()


copy(): To make a copy of a set.
isdisjoint() : Returns True if sets have no common items
issubset() : Returns True if a set is a subset of other.
issuperset() : Returns True  if a set is a superset of other.


frozen set : It is readonly form of set

it defined using frozenset()

s = frozenset({1, 2, 3, 4, 5})

print(type(s)) #<class 'frozenset'>
