dictionary : 

It is also a collection type where data is stored in the form of key, value pairs. 
It is defined using curly braces.

e.g:

car = {
   "brand" : "Hyundai",
   "model" : "Creta",
   "year" : 2025
}

print(type(car)) #<class 'dict'>

how to define :

1) using {} and data in key:value pair
2) using dict()

example : 

student = {
   "name" : "Akshaya",
   "class" : "9th",
   "year" : 2025
}

print(student)

example :

student = dict({ "Akshaya", "9th", 2025 })

print(student)
