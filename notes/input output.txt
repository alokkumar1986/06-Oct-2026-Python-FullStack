input output : 

input() : This method is used to take input to the program.
print() : This method is used to get output from the program.

input():  
===================
When we take input, it is by default str.
in order to convert its type, we generally use type casting. 

int() : to convert to integer
float(): to convert to float
complex() : to convert to complex
str() : to convert to string
bool() : to convert to boolean

Note : whenever we take input, we must use type casting.

type casting :

1) implicit : auto convert
2) explicit  : forcefully convert

output : 
#===============
For getting output from a program we use print().

print() always gives output in a new line. 

In order to format the output in multiple line of single print(), we use escape sequence.

escape sequence :
=================

\n : new line
\t : horizontal tab
\r : carriage return
\/ : single slash
\" : double quote
\' : single quote 

Type of print()
#=================
1) print() with string :

print('Aptech')  #Aptech

2) print() with a variable :

a = 10
print(a) #10

3) print() with multiple string:

print('Aptech', 'Learning', 'Center')  #Aptech Learning Center

4) print() with multiple variable :

a = 10
b = 'Ashok'
c = 3+2j
print(a, b, c) # 10 Ashok 3+2j

 
5) print() with string and variable

a = 10
b = 20
print('Value of a :', a, 'Value of b :', b)

6) print() with {} 
a = 10
b = 20
print('Value of a : {} Value of b : {}'.format(a, b))

7) print() with sep=
a = 10
b = 20
print(a,b, sep=',') #10 , 20

8) print() with end=

print('Aptech')
print('Learning')
print('Center')

9) print() with both sep= and end=

print('Aptech', 'Learning', sep='/', end=' ')
print('Center')
